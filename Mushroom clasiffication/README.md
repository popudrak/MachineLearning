# Overview
The goal of the project is to build a classification model that predicts whether a given mushroom is edible or poisonous based on its physical and chemical characteristics. 
A key aspect was to process the data andcompare the effectiveness of several classification models.

# Dataset
The dataset “Mushroom Dataset” contains only categorical variables, which allows classification analysis using different machine learning algorithms. 

UCI Repo: https://archive.ics.uci.edu/dataset/73/mushroom
Files: agaricus-lepiota.names, agaricus-lepiota.data
