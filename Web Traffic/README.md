# Overview
Task was to create, train and evaluate a neural network model in the form of a deep autoencoder to distinguish between normal network traffic and anomalous traffic. 
The nature of which indicates various forms of attack (scanning, DoS/DDoS, attempts at unauthorized access or elevation of privileges) on the network and the computers within it.

# Dataset
MIT Lincoln Labs: https://kdd.ics.uci.edu/databases/kddcup99/kddcup99.html

Files: kddcup.names, kddcup.data_10_percent.gz
