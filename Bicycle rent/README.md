# Overview
The task was to create, train and evaluate regression models predicting the daily number of bicycle rentals based on meteorological, calendar and seasonal data.
The project used the “Bike Sharing Dataset,” which includes data from Washington DC's Capital Bikeshare system. 

# Goal
The goal was to build a model with the highest possible accuracy of forecasts, as well as to identify the most important characteristics affecting the number of rentals.

# Dataset
UCI repo: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

File: day.csv
